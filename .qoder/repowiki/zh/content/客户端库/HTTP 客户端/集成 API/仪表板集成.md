### 实时更新机制与事件流
- SSE事件流：EventStreamService 支持 text/event-stream，从网关拉取实时事件，解析 event/data 行，回调上层处理
- 使用场景：前端仪表盘可订阅运行事件或会话事件，实现无刷新更新
- 注意事项：连接断开需重连；异常吞吐以保证稳定性

```mermaid
flowchart TD
Start(["开始"]) --> CreateReq["创建 HTTP 请求<br/>Accept: text/event-stream"]
CreateReq --> Send["发送请求并等待响应头"]
Send --> RespOk{"响应成功？"}
RespOk --> |否| Fail["标记未连接并结束"]
RespOk --> |是| Mark["标记已连接"]
Mark --> Read["逐行读取流"]
Read --> Line{"行类型"}
Line --> |空行| Flush["输出事件回调"]
Line --> |注释/心跳| Skip["跳过"]
Line --> |event/data| Buffer["缓冲事件/数据"]
Flush --> Read
Skip --> Read
Buffer --> Read
Read --> Done(["结束"])
```

## 故障排除指南
- 无法访问仪表板：检查鉴权与CSRF配置；确认 /api/integration/dashboard 路由映射
- 响应为空或字段缺失：核对客户端 BaseURL 与 API Key；检查网关日志
- SSE 连接失败：确认 Accept: text/event-stream；检查网络与跨域设置
- 前端主题异常：确认 data-theme 设置与 localStorage 存储
