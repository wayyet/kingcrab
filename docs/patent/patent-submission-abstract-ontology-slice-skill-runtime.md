# 说明书摘要

## 发明名称

一种将面向任务的本体切片转换为技能运行时正式输入的方法、系统、设备及存储介质。

## 摘要正文

本发明公开了一种将面向任务的本体切片转换为技能运行时正式输入的方法、系统、设备及存储介质，属于人工智能工程化与智能体运行时治理技术领域。该方法包括：获取请求信息与领域本体信息；基于请求信息从领域本体中抽取最小语义闭包，形成任务导向本体切片；将本体切片按至少一种目标视图投影生成投影文件；基于投影文件构建或维护契约索引；由技能加载器自动发现并绑定契约索引；在请求时执行主题与目标视图的动态路由；对目标路由对应投影文件执行阻断检查；在阻断检查通过时，将投影文件转换为技能运行时正式输入并注入运行时消费链路。所述目标视图包括领域模型视图、数据结构约束视图、提示约束视图和工作流契约视图中的一种或多种。所述阻断检查至少用于处理主题歧义、视图歧义、投影缺失、解析失败和多生产方同分歧义。与现有技术相比，本发明实现了从离线语义整理到在线请求执行的受控闭环，提升了语义输入一致性、路由可解释性、运行稳定性与治理可审计性。
