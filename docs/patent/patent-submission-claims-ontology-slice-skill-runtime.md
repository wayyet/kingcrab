# 权利要求书

## 一、独立权利要求

1. 一种将面向任务的本体切片转换为技能运行时正式输入的方法，其特征在于，包括：
获取待处理任务对应的请求信息以及与所述请求信息相关的领域本体信息；
基于所述请求信息，从所述领域本体信息中抽取与当前任务对应的最小语义闭包，以生成任务导向本体切片；
将所述本体切片按至少一种目标消费视图进行投影，生成供消费技能使用的投影文件；
基于所述投影文件构建或维护契约索引，其中所述契约索引用于组织主题、目标视图、投影文件路径及路由规则；
由技能加载器对所述契约索引执行自动发现与绑定，以使所述契约索引进入技能运行时的可解析输入集合；
在接收到用户请求时，于请求时基于当前用户请求对候选主题执行动态选择，并在选定主题内对候选目标视图执行动态选择，以得到目标路由；
针对所述目标路由对应的投影文件执行阻断检查，以判断所述投影文件是否满足进入运行时消费链路的条件；
在所述阻断检查通过时，将所述投影文件转换为技能运行时的正式输入并注入运行时消费链路，以控制所述消费技能后续执行。

9. 一种用于将面向任务的本体切片转换为技能运行时正式输入的系统，其特征在于，包括：
切片构建模块，用于基于请求信息从领域本体信息中抽取与当前任务对应的最小语义闭包，以生成任务导向本体切片；
投影生成模块，用于将所述本体切片按至少一种目标消费视图进行投影，以生成供消费技能使用的投影文件；
契约管理模块，用于基于所述投影文件构建或维护契约索引；
加载发现模块，用于自动发现并绑定所述契约索引；
路由解析模块，用于在请求时对候选主题和候选目标视图执行动态选择，以确定目标路由；
阻断模块，用于对所述目标路由对应的投影文件执行阻断检查；
运行时注入模块，用于在阻断检查通过时，将所述投影文件转换为技能运行时正式输入并注入运行时消费链路。

10. 一种电子设备，其特征在于，包括处理器和存储器，所述存储器中存储有计算机程序，所述计算机程序被所述处理器执行时，使所述电子设备执行权利要求1至8任一项所述的方法。

11. 一种计算机可读存储介质，其上存储有计算机程序，其特征在于，所述计算机程序被处理器执行时，实现权利要求1至8任一项所述的方法。

## 二、从属权利要求

2. 根据权利要求1所述的方法，其特征在于，所述本体切片至少包括以下信息中的两种以上：概念、关系、约束和来源；其中所述来源用于表征本体切片语义结论的来源信息，以支持追溯。

3. 根据权利要求1所述的方法，其特征在于，所述至少一种目标消费视图包括以下任一种或多种：领域模型视图、数据结构约束视图、提示约束视图和工作流契约视图。

4. 根据权利要求1所述的方法，其特征在于，所述契约索引至少包括以下信息中的一种或多种：生产方标识、生产方优先级、默认选择策略、主题评分规则、目标视图评分规则、主题与目标视图组织关系以及投影文件路径。

5. 根据权利要求1所述的方法，其特征在于，对候选主题执行动态选择包括：根据当前用户请求中的任务信号，对多个候选主题进行评分；在多个候选主题中选择得分满足预设条件的主题；当候选主题之间分值差小于预设阈值时，判定为主题歧义。

6. 根据权利要求1所述的方法，其特征在于，对候选目标视图执行动态选择包括：在选定主题内，根据当前用户请求对应消费意图对多个候选目标视图进行评分；在多个候选目标视图中选择得分满足预设条件的目标视图；当候选目标视图之间分值差小于预设阈值时，判定为视图歧义。

7. 根据权利要求1所述的方法，其特征在于，所述阻断检查至少包括以下任一项检测：
主题选择不明确；
目标视图选择不明确；
投影文件缺失；
投影文件解析失败；
路由缺少必需字段；
目标视图状态不满足预设可消费状态；
投影文件中存在未决问题且阻断策略生效；
未解决项处理策略指示需阻断或升级；
多生产方结果无法打破同分歧义。

8. 根据权利要求1所述的方法，其特征在于，将所述投影文件转换为技能运行时正式输入包括：从所述投影文件中提取至少一种运行时控制信息，所述运行时控制信息包括提示补丁、允许术语、禁止性假设、必要澄清项、推理路径、来源摘要和裁剪项中的一种或多种，并将所述运行时控制信息注入技能指令、执行上下文约束、结构化防护规则或流程控制输入中。

12. 根据权利要求1所述的方法，其特征在于，在同一消费技能绑定多个生产方契约集合的情况下，还包括：针对每个生产方分别执行路由解析，得到多个候选路由；按照候选路由评分值和生产方优先级进行排序；并根据排序结果确定最终路由。

13. 根据权利要求12所述的方法，其特征在于，当两个或多个候选路由的评分值与生产方优先级同时相同时，执行阻断而不选择任一候选路由。

14. 根据权利要求1所述的方法，其特征在于，技能加载器在自动发现与绑定契约索引后，还输出发现诊断信息，所述发现诊断信息包括以下状态中的一种或多种：未发现、已绑定、部分绑定、解析失败和枚举失败。

15. 根据权利要求1所述的方法，其特征在于，对本体切片和投影文件离线生成产物采用第一类模式校验机制，对契约索引和运行时投影文件采用第二类模式校验机制，以将生产方模板治理与运行时契约治理分层。

## 三、代理人使用提示

1. 如需进一步拉宽保护范围，可将自动发现步骤由独立权利要求下沉至从属权利要求。
2. 如需加强区别性，可在独立权利要求保留“请求时双层路由 + 阻断通过后注入”的串联关系。
3. 如需增强防绕过能力，可保留多生产方同分阻断、发现诊断状态和分层治理从属权利要求。
