# 说明书

## 一、发明名称

一种将面向任务的本体切片转换为技能运行时正式输入的方法、系统、设备及存储介质。

## 二、技术领域

本发明涉及人工智能工程化、知识建模、智能体技能编排及运行时控制技术领域，尤其涉及一种将领域本体中与当前任务相关的最小语义子图转换为可发现、可路由、可阻断、可治理的技能运行时正式输入的技术方案。

## 三、背景技术

随着大模型与智能体系统在复杂业务中的应用增加，领域本体被广泛用于统一术语、概念关系和约束边界。但现有技术通常存在以下问题：

1. 直接使用完整本体或其摘要作为提示输入，语义冗余高，运行时需自行裁剪，易引入无关语义和错误推断。
2. 本体局部抽取结果多停留在离线文档层，缺少从本体切片到消费技能正式输入的转换机制。
3. 即使存在投影文件，也常缺乏契约索引与自动发现机制，运行时难以按请求动态选择主题和目标视图。
4. 在主题歧义、视图冲突、投影缺失、未决问题存在或多生产方打平时，系统常静默降级或继续执行，缺少正式阻断。
5. 多生产方并存时常采用覆盖式策略，缺少可解释、可审计的受控裁决。

因此，现有技术尚缺少一条将任务导向本体切片稳定演进为技能运行时正式输入的完整控制链路。

## 四、发明内容

### （一）发明目的

本发明旨在提供一种标准化运行机制，使本体语义资产在请求级执行过程中被正式消费，解决本体输入过载、语义漂移、路由不可控和治理不可审计等问题。

### （二）技术方案

为实现上述目的，本发明提供一种方法，包括：

S1、获取待处理任务对应的请求信息以及与请求信息相关的领域本体信息；

S2、基于请求信息从领域本体信息中抽取与当前任务对应的最小语义闭包，形成任务导向本体切片；

S3、将本体切片按至少一种目标视图进行投影，生成供消费技能使用的投影文件；

S4、基于投影文件构建或维护契约索引，所述契约索引用于组织主题、目标视图、投影文件路径及路由规则；

S5、由技能加载器对契约索引执行自动发现与绑定，使契约索引进入技能运行时可解析输入集合；

S6、在接收到用户请求时，于请求时基于当前请求对候选主题执行动态选择，并在选定主题内对候选目标视图执行动态选择，得到目标路由；

S7、针对目标路由对应投影文件执行阻断检查，以判断投影文件是否满足进入运行时消费链路的条件；

S8、在阻断检查通过时，将投影文件转换为技能运行时正式输入并注入运行时消费链路，以控制消费技能后续执行。

优选地，目标视图包括领域模型视图、数据结构约束视图、提示约束视图、工作流契约视图中的一种或多种。

优选地，阻断检查至少包括以下任一项：主题歧义、目标视图歧义、投影文件缺失、投影文件解析失败、必需字段缺失、目标视图状态不可消费、未决问题触发阻断策略、多生产方候选评分值与优先级同时打平。

优选地，运行时正式输入包括提示补丁、允许术语、禁止性假设、必要澄清项、推理路径、来源摘要和裁剪项中的一种或多种。

### （三）有益效果

与现有技术相比，本发明至少具有以下效果：

1. 将本体切片从离线语义整理产物升级为运行时正式输入。
2. 通过任务导向最小语义闭包显著降低运行时语义噪声。
3. 通过多目标视图投影实现同源语义在不同消费场景的稳定复用。
4. 通过契约索引与自动发现机制实现运行时可绑定、可诊断。
5. 通过请求级双层路由提升任务适配能力。
6. 通过阻断机制在不确定情形下停止执行，降低错误传播。
7. 通过多生产方受控裁决提升结果可解释性和治理可审计性。

## 六、具体实施方式

以下结合实施方式对本发明作进一步说明。应当理解，实施方式仅用于说明本发明，不用于限定本发明保护范围。

### 实施方式一：提示约束场景

针对“会话记忆写入边界”任务，先从领域本体中抽取与该任务直接相关的概念、关系、约束和来源，生成本体切片；再投影为提示约束视图投影文件。请求命中对应主题后执行目标视图选择与阻断检查；若未决问题触发阻断策略，则输出澄清请求并停止注入；若通过阻断检查，则将允许术语、禁止性假设和必要澄清项注入运行时提示补丁。

### 实施方式二：多视图复用场景

同一本体切片同时投影为领域模型视图、数据结构约束视图与提示约束视图。当请求偏向代码对象建模时选择领域模型视图；当请求偏向结构校验时选择数据结构约束视图；当请求偏向推理边界时选择提示约束视图。由于三类视图来源于同一切片，可保持术语和约束一致。

### 实施方式三：多生产方受控裁决场景

在同一消费技能绑定多个生产方契约集合时，对每个生产方独立执行主题与目标视图路由解析，汇总候选路由后按评分值降序排序；评分值相同时按生产方优先级降序排序；若评分值与优先级均相同，则判定不可消解歧义并阻断。

### 实施方式四：分层治理场景

生产方侧对本体切片和投影模板进行离线校验；消费侧对契约索引和运行时投影进行在线校验；运行时执行请求级路由、阻断与注入；诊断层输出发现状态、评分依据、阻断原因及同分裁决依据，以支持排障和审计。

## 七、可替代实施方式

1. 主题与目标视图评分模型、权重与阈值可按业务需求调整。
2. 目标视图类型可扩展为其他结构化交付视图。
3. 运行时注入可表现为提示补丁、守卫约束、工具调用前置条件或流程门控规则。
4. 阻断策略可按技能、主题、生产方或部署环境分级配置。
5. 多生产方裁决可引入来源可信度、更新时间等附加因子，但在不可消解歧义时保持阻断原则。

## 九、结论

本发明的实质创新在于：建立“任务导向本体切片 -> 投影文件 -> 契约索引 -> 请求时双层路由 -> 阻断检查 -> 运行时注入”的受控链路，使语义治理能力从离线文档层进入在线执行层，并实现可复用、可解释、可审计的工程化落地。
